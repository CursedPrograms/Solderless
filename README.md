# Solderless

A breadboard you build guitar and violin pedals on, and play through live. Drop in resistors,
caps, diodes, transistors and pots, wire them up, and hear the circuit as you build it. Like a
real breadboard, nothing works until the circuit is complete. VST3 plugin + standalone app with
ASIO.
